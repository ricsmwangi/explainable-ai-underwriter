# Explainable AI Underwriter

A transparent machine learning framework for integrating alternative data 
(telematics and rent payment history) into insurance risk assessment.

## Research Overview

Traditional insurance underwriting relies on credit-based insurance scores that 
are opaque, exclude credit-invisible populations, and fail emerging regulatory 
requirements for explainability. This project builds an **Explainable AI 
Underwriter** that integrates alternative data sources while maintaining 
interpretability and fairness.

## Research Questions

- **RQ1:** What is the incremental predictive value of telematics data over 
  traditional underwriting features?
- **RQ2:** What is the incremental predictive value of rent payment data over 
  traditional underwriting features?
- **RQ3:** Does a multi-source model combining telematics and rent payment 
  data outperform single-source models?
- **RQ4:** Can SHAP-based explanations provide faithful and human-interpretable 
  justifications for multi-source underwriting decisions?
- **RQ5:** Does the integration of alternative data sources introduce or 
  mitigate disparate impact across demographic groups?
